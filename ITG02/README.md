# ITG02 — Викторина с графическим интерфейсом на Python

Десктопная игра «Кто хочет стать миллионером» по ТЗ урока **ITG02** курса ZeroCoder.

Игра автономная: интернет, платные API и хостинг не нужны. Запускается как обычное Python-приложение.

## Что умеет

- Главное меню: **Играть** и **Выход**
- 15 вопросов с четырьмя вариантами ответа
- Шкала выигрыша и несгораемые суммы после 5-го и 10-го вопроса
- Подсказки: **50:50**, **Звонок другу** (≈80% верный ответ), **Помощь зала** (псевдографик)
- Победа, поражение и переход к следующему вопросу
- Кнопка «Сыграть ещё раз»

## Запуск

Нужен **Python 3.10+**. Tkinter входит в стандартную библиотеку (на Linux иногда ставят пакет `python3-tk`).

```bash
cd ITG02
python main.py
```

Сторонние пакеты не требуются. Файл `requirements.txt` это подтверждает.

## Как добавить вопросы

Отредактируйте `questions.json`. У каждого вопроса:

- `text` — формулировка
- `options` — ровно 4 варианта
- `correct` — индекс верного ответа (`0`–`3`)
- `difficulty` — `easy` / `medium` / `hard`

Для полной шкалы в файле должно быть не меньше 15 вопросов.

## Структура

- `main.py` — запуск
- `game_logic.py` — вопросы, выигрыш, подсказки (`Question`, `GameState`)
- `ui.py` — интерфейс Tkinter
- `questions.json` — база вопросов
