## Задание
Консольная программа: запрос → ru.wikipedia.org → листать параграфы, переходить по связанным статьям, выход.

## Что сделано хорошо
- Selenium, поле `#searchInput`, переход на статью из выдачи.
- Постраничный вывод параграфов с меню «следующий / назад».
- Связанные ссылки из hatnote, переход по номеру.
- Запасной браузер Firefox, если Chrome не стартовал.

## Замечания
- Голые `except:` без типа и лога — ошибки поиска глотаются.
- `time.sleep` фиксированные, без явных ожиданий WebDriverWait.
